# GravelScope

Static Gravel Calculator website for `gravelscope.website`.

## Deploy to Cloudflare Pages

- Push this folder to the GitHub repository.
- Cloudflare Pages serves the repository root as the static site.
- Framework preset: None.
- Build command: leave blank.
- Build output directory: `/` (repository root).

## AdSense

- Publisher ID: `pub-8025420721885884`.
- AdSense loader is included in every HTML page.
- `ads.txt` is located at the repository root and should resolve at `https://gravelscope.website/ads.txt`.
- Before requesting review, verify the live `ads.txt` URL and make sure the contact email receives messages.
- Configure privacy/consent messaging in AdSense where legally required.

## Search

- `robots.txt` points to `/sitemap.xml`.
- `sitemap.xml` includes the calculator, policy pages and gravel planning guides.
