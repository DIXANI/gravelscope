# GravelScope

Static Gravel Calculator website for `gravelscope.website`.

## Deploy to Cloudflare Pages

- Push this folder to a GitHub repository.
- In Cloudflare Pages, connect the repository.
- Framework preset: None.
- Build command: leave blank.
- Build output directory: `/` (repository root).
- Add `gravelscope.website` as the custom domain after the preview is verified.

## Before public launch

- Configure `hello@gravelscope.website` or change the contact address in the HTML files.
- Verify the production canonical URL is correct.
- Add the domain to Google Search Console and submit `/sitemap.xml`.
- If analytics or ads are enabled, update the Privacy Policy and add any legally required consent flow.
